## Testing

The following features were tested manually:

- Adding an ingredient to the pantry.
- Viewing pantry ingredients.
- Updating an ingredient's quantity.
- Deleting an ingredient.
- Checking that pantry data remains saved after reopening the app.
- Checking the suggested recipes screen with an empty pantry and with a limited number of ingredients.

Recipe matching with all required quantities and ingredients has not yet been fully verified.
